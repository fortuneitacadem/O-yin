# O-yin (Odoo 19.0 O'zbek tili bilan)

Ushbu loyiha Odoo 19.0 platformasidan foydalangan holda O'zbek tiliga to'liq moslashtirilgan (100% Uzbek localization) biznes boshqaruv tizimidir.

## Loyiha tarkibi
- `odoo-19.0/` - Odoo platformasining asosiy kodi.
- `run.py` - Tizimni osongina ishga tushirish skripti.

## Ishga tushirish (Run)
Loyihani ishga tushirish uchun avval kompyuteringizda Python 3.10+ va PostgreSQL 13+ o'rnatilganligiga ishonch hosil qiling.

Keyin quyidagi buyruqni bering:
```bash
python run.py
```

## O'zbek tili
Odoo Bot va barcha asosiy menyular O'zbek tiliga tarjima qilingan. Agar qo'shimcha tarjima kerak bo'lsa, `translations` bo'limidan sozlash mumkin.
